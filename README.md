\#Это лабараторная №2 по исрпо

Данный репозиторий включает в себя два исполнительных файла, содержащих следующие функции:
\*\*ToBase\*\* - функция перевода чисел из 10 системы счисления в любую другую до 32
\*\*square\*\* - функция возведения числа в квадрат



\##Пример использования:



\*\*ToBase\*\*

```

ToBase(123, 12) #Вывод: A3

```



\*\*square\*\*

```

square(12) #Вывод: 144

```



Важно!!!

>Функция \*\*ToBase\*\* возвращает строку (тип \_str\_)
