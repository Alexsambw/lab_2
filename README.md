# Лабораторная работа №2 по ИСРПО

Данный репозиторий включает в себя два исполняемых файла, содержащих следующие функции:

- **ToBase** — функция перевода чисел из 10-й системы счисления в любую другую (до 32)
- **square** — функция возведения числа в квадрат

## Пример использования

### ToBase

```python
ToBase(123, 12) # Вывод: A3
```

### square

```python
square(12) # Вывод: 144
```

> **Важно!** Функция **ToBase** возвращает строку (тип `str`).
