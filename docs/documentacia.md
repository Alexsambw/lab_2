\#Я создал две функции на Python, они никак между собой не связаны



Первая (\\\*\\\*ToBase\\\*\\\*) меняет систему счисления, другая (\\\*\\\*square\\\*\\\*) - просто возводит число в квадрат



Обе функции принимают на вход целые числа (\_int\_)

У функции \\\*\\\*ToBase\\\*\\\* два аргумента: n - число в 10 cc и base - число основание сс для искомого результата



Функция \\\*\\\*ToBase\\\*\\\* возвращает строку (\_str\_)

Функция \\\*\\\*square\\\*\\\* возвращает целое число (\_int\_)



Примеры вызова:



>ToBase(123, 12) #Вывод: A3

>ToBase(47, 4) #Вывод: 233

>ToBase(10, 8) #Вывод: 12



>square(12) #Вывод: 144

>square(4) #Вывод: 16

>square(-8) #Вывод: 64
