# Лабораторная работа №2 по ИСРПО

Я создал две функции на Python, они никак между собой не связаны.

- **ToBase** — меняет систему счисления.
- **square** — просто возводит число в квадрат.

Обе функции принимают на вход целые числа (`int`).

## Описание функций

### ToBase
Функция имеет два аргумента:
- `n` — число в 10-й системе счисления;
- `base` — основание системы счисления для искомого результата (до 32).

> **Возвращает:** строку (`str`)

### square
Функция принимает одно целое число.

> **Возвращает:** целое число (`int`)

## Примеры вызова

```python
# ToBase
ToBase(123, 12) # Вывод: A3
ToBase(47, 4)   # Вывод: 233
ToBase(10, 8)   # Вывод: 12

# square
square(12)      # Вывод: 144
square(4)       # Вывод: 16
square(-8)      # Вывод: 64
```
